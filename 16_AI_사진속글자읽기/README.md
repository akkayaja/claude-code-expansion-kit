# 16. 사진 속 글자 읽기 (OCR)

> **얻는 능력:** 영수증·메뉴판·명함 사진에서 **글자와 숫자를 뽑아 표로** 만드는 능력

**왜 배우나요?** 종이와 사진은 아직도 많아요. 사진을 찍기만 하면 엑셀에 들어가게 만들 수 있으면 활용처가 아주 넓어요.

## 📁 들어 있는 파일
- `images/영수증_01~06.png` – 가상 영수증 사진 6장
- `정답_영수증.csv` – 가게, 날짜, 합계

## 🧭 기본 미션 (순서대로)
1. 영수증 사진을 직접 보고 무엇을 뽑을지 정한다 (가게, 날짜, 품목, 합계)
2. Claude와 함께 맥에 내장된 글자 인식(Apple Vision, `ocrmac` 등)을 써서 글자를 뽑는다
3. 뽑은 글자에서 가게·날짜·합계만 골라 CSV로 만든다
4. `정답_영수증.csv`와 비교한다
5. 틀린 것이 있으면 왜 틀렸는지 (글꼴, 기울기, 숫자 쉼표) 적는다

## 🔥 도전 미션 (기본을 끝냈다면)
- AI(Claude나 ChatGPT)에게 사진을 직접 보여 주는 방식과 정확도 비교하기
- 1단계 05번(PDF 추출) 결과와 합쳐 '지출 정리 도구' 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
images 폴더 영수증 사진에서 가게, 날짜, 합계를 뽑아 CSV로 만들어 줘. 인터넷 없이 내 맥에서 돌아가는 방법으로.
```
```
결과를 정답_영수증.csv 와 비교해서 틀린 것과 이유를 보여 줘.
```
