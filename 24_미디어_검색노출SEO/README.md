# 24. 검색에 잘 나오게 만들기 (SEO 기초)

> **얻는 능력:** 내 웹페이지가 **검색에서 잘 보이도록 점검하고 고치는** 능력

**왜 배우나요?** 블로그나 가게 홈페이지를 만들어도 검색에 안 나오면 아무도 못 와요. 기본 점검만 해도 차이가 커요.

## 📁 들어 있는 파일
- `연습사이트/` – 검색 노출 문제를 **일부러 심어 둔** 가상 가게 홈페이지 (5페이지)
- `SEO_체크리스트.md` – 점검 항목
- `정답_심어둔문제.md` – 심어 둔 문제 (**먼저 보지 마세요**)

## 🧭 기본 미션 (순서대로)
1. 체크리스트를 읽고 모르는 단어를 쉬운 말로 적는다
2. 연습 사이트를 열어(`python3 -m http.server 8771`) 체크리스트대로 내가 먼저 점검한다
3. Claude와 함께 모든 페이지를 자동으로 점검하는 스크립트를 만든다
4. 정답과 비교해 몇 개 찾았는지 센다
5. 고친 버전을 `고친사이트/`에 만든다 (원본은 그대로)

## 🔥 도전 미션 (기본을 끝냈다면)
- 22번 내 블로그를 같은 스크립트로 점검하기
- 검색 결과에 보일 제목·설명을 3안씩 만들어 비교하기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
연습사이트 폴더의 모든 html 을 SEO_체크리스트.md 기준으로 점검하는 스크립트를 짜 줘. 정답 파일은 열지 마.
```
```
찾은 문제를 고친 버전을 고친사이트 폴더에 만들어 줘.
```
