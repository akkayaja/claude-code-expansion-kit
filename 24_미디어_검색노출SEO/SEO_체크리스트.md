# SEO 기본 체크리스트

| # | 확인할 것 | 내 말로 설명 |
|---|---|---|
| 1 | 모든 페이지에 `<title>`이 있다 | |
| 2 | 페이지마다 title이 **서로 다르다** | |
| 3 | 모든 페이지에 `meta description`(검색 결과 설명)이 있다 | |
| 4 | 페이지마다 `<h1>`이 **딱 하나** 있다 | |
| 5 | 이미지에 `alt`(그림 설명)가 있다 | |
| 6 | 사이트 안 링크가 모두 존재하는 페이지로 간다 | |
| 7 | 휴대폰 화면 설정(`meta viewport`)이 있다 | |
| 8 | `robots.txt`와 `sitemap.xml`이 있다 | |
