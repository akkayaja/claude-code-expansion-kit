# 20. 노션 자동화

> **얻는 능력:** 노션 데이터베이스에 **자동으로 기록을 쌓고 읽어 오는** 능력

**왜 배우나요?** 노션은 많은 사람이 일정·기록용으로 써요. 코드로 연결하면 '자동으로 쌓이는 기록장'이 돼요.

## 📁 들어 있는 파일
- `학습기록_DB구조.md` – 노션에 만들 데이터베이스 칸 구성
- `.env.example` – 노션 통합 토큰 자리

## 🧭 기본 미션 (순서대로)
1. 노션에 '학습 기록' 데이터베이스를 직접 만든다 (구조는 파일 참고)
2. 노션 '통합(Integration)'을 만들고 토큰을 **직접** `.env`에 넣는다. 데이터베이스에 통합을 연결한다
3. 스크립트로 한 줄 기록을 추가해 본다
4. 1단계 `학습일지/` 폴더의 md 파일들을 읽어 노션 DB에 한꺼번에 넣는다
5. 노션에서 '이번 주 기록'을 읽어 와 요약하는 스크립트를 만든다
