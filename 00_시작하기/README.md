# 00. 시작하기 — 도구 준비

확장 키트는 1단계보다 **여러 도구**를 써요. 처음 한 번만 준비하면 돼요.

## 1. 이미 이 컴퓨터에 있는 것 (확인만)
| 도구 | 쓰는 곳 | 확인 명령 |
|---|---|---|
| ffmpeg | 영상·음성 편집 (02~05, 15, 18) | `ffmpeg -version` |
| Node.js | 웹 도구, 영상 만들기, n8n (05, 13, 21, 22) | `node -v` |
| HyperFrames | 코드로 영상 만들기 (05) | `npx hyperframes --help` |
| 맥 음성 (Yuna) | 목소리 합성 (18) | `say -v Yuna 안녕하세요` |
| ChatGPT 앱 안의 Codex | 그림 만들기 (07, 08, 10, 13, 22) | 아래 2번 |

## 2. Codex(ChatGPT) 연결 — 그림 만들기용
ChatGPT 앱 안에 Codex 명령어 도구가 들어 있어요. 터미널 어디서나 `codex`라고 부를 수 있게 **바로가기**를 만들어요.

```
ln -s /Applications/ChatGPT.app/Contents/Resources/codex-cli/bin/codex ~/.local/bin/codex
```
- `ln -s 원본 바로가기` = 바탕화면 바로가기 아이콘을 만드는 것과 같아요.
- `~/.local/bin`은 이미 ffmpeg, gh가 들어 있는 '내 도구 서랍'이에요.

확인:
```
codex --version
codex login status
```
`Logged in using ChatGPT`가 나오면 준비 끝이에요.

### 그림 한 장 시험하기
```
공통도구/이미지만들기.sh "파란 하늘 아래 노란 우산 하나, 단순한 일러스트" 시험그림.png
```
- 1~2분 뒤 `시험그림.png`가 생기면 성공이에요.
- 이 도구는 Claude Code가 대신 실행해 줄 수도 있어요: "공통도구/이미지만들기.sh 로 ○○ 그림 만들어 줘"

### 원칙
- **내 ChatGPT 사용량**을 써요. 연습할 때는 한 번에 1~3장만.
- 실존 인물, 유명 캐릭터, 브랜드 로고, 남의 작품 화풍은 요청하지 않아요.
- 그림 안에 한글 글자를 넣으면 깨지기 쉬워요. **글자는 코드로 얹는 것**이 이 키트의 방식이에요 (07번).

### 문제가 생기면
- `command not found: codex` → 1번 바로가기 명령을 다시 실행
- 로그인 문제 → ChatGPT 앱을 열어 로그인 상태 확인 (로그인은 **직접** 해요)
- 그림이 안 생김 → `codex exec "고양이 그림 하나 만들어 줘"`를 직접 실행해 오류 메시지를 Claude에게 보여 주기
