# 게임 기획서: 퇴근 버스 잡기

## 한 줄 설명
퇴근까지 남은 60초 동안 떨어지는 '칼퇴'와 '커피'는 받고 '야근 서류'는 피해서, 에너지를 지킨 채 버스에 타는 게임.

## 플레이어가 하는 것 (조작)
- 키보드: ← → (또는 A, D) 키로 직장인을 왼쪽·오른쪽으로 움직인다
- 스페이스바: 시작 / 다시 하기
- 터치: (도전 미션) 화면 왼쪽·오른쪽을 누르고 있으면 움직임

## 규칙
1. 위에서 세 가지 물건이 떨어진다: 🕕 칼퇴 시계, ☕ 커피, 📄 야근 서류
2. 직장인은 화면 맨 아래에서 좌우로만 움직인다
3. 에너지(❤️)는 3칸으로 시작한다
4. ☕ 커피를 받으면 3초 동안 걸음이 빨라진다 (내 규칙)
5. 📄 야근 서류를 받으면 에너지가 1칸 줄고, 화면이 잠깐 빨갛게 번쩍인다
6. 바닥에 떨어진 물건은 그냥 사라진다 (놓쳐도 감점 없음)

## 점수
- 점수가 오르는 경우: 🕕 칼퇴 시계 +10점, ☕ 커피 +5점
- 점수가 깎이는 경우: 점수는 깎지 않는다. 대신 📄 야근 서류를 받으면 에너지 −1

## 끝나는 조건
- 이기는 조건: 60초를 버티면 "🚌 버스 탑승!" (남은 에너지 1칸당 보너스 +20점)
- 지는 조건: 에너지가 0이 되면 "😩 오늘도 야근…"

## 난이도 변화
- 시간이 지나면: (미션 4에서 넣음) 15초마다 떨어지는 속도가 빨라지고, 야근 서류가 나오는 비율이 늘어난다
- 최고 점수는 브라우저에 저장해서 다음 판에 보여 준다 (미션 4)

## 화면 그림 (대충)
```
┌──────────────────────────────┐
│ 점수 120   ❤️❤️🤍   남은 42초 │  ← 상태 표시줄
│                              │
│     🕕          📄           │
│            ☕                │  ← 떨어지는 물건
│   📄             🕕          │
│                              │
│ ─────────── 🧑‍💼 ─────────── │  ← 나 (← → 로 이동)
└──────────────────────────────┘
```

## 코드에서 '상태'가 되는 것 (미리 정리)
| 상태 | 처음 값 | 바뀌는 때 |
|---|---|---|
| 점수 | 0 | 칼퇴·커피를 받을 때 |
| 에너지 | 3 | 야근 서류를 받을 때 |
| 남은 시간 | 60초 | 매 순간 줄어듦 |
| 내 위치(x) | 화면 가운데 | ← → 키를 누를 때 |
| 떨어지는 물건 목록 | 비어 있음 | 새로 생기거나, 받거나, 바닥에 닿을 때 |
| 게임 단계 | 시작 전 | 시작 → 진행 중 → 끝 |
