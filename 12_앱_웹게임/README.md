# 12. 간단한 웹 게임 만들기

> **얻는 능력:** 규칙을 설계하고 **상태(점수, 시간, 레벨)**가 바뀌는 프로그램을 만드는 능력

**왜 배우나요?** 게임은 '입력 → 상태 변화 → 화면 갱신'의 가장 좋은 연습이에요. 이 구조를 알면 웹앱 대부분이 같은 원리라는 게 보여요.

## 📁 들어 있는 파일
- `게임기획서_양식.md` – 규칙, 승리·패배 조건, 점수 계산을 적는 양식
- `아이디어_예시.md` – 내가 직접 고르거나 바꿔 쓸 게임 아이디어 6개

## 🧭 기본 미션 (순서대로)
1. 아이디어 예시를 참고해 **나만의 게임 규칙**을 기획서에 먼저 적는다 (유명 게임 따라 하기 말고 내 규칙)
2. Claude와 함께 HTML 파일 하나로 가장 단순한 버전을 만든다 (움직임 + 점수)
3. 직접 5판 해 보고 너무 쉬운지·어려운지 적는다
4. 난이도(속도, 시간)를 조절하고 최고 점수 저장을 넣는다
5. 11번 1단계 웹페이지 배포처럼 인터넷에 올려 친구에게 링크를 보낸다

## 🔥 도전 미션 (기본을 끝냈다면)
- 휴대폰 터치로도 할 수 있게 만들기
- 효과음 넣기 (18번처럼 직접 만든 소리)
