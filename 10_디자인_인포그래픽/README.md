# 10. 데이터로 인포그래픽 포스터 만들기

> **얻는 능력:** 숫자 데이터를 **한 장짜리 그림 설명**으로 만드는 능력

**왜 배우나요?** 보고서는 안 읽어도 그림 한 장은 봐요. 데이터를 한눈에 보이게 만드는 건 어느 직무에서나 통하는 능력이에요.

## 📁 들어 있는 파일
- `data/1인가구_생활비.csv` – 가상 설문 300명의 항목별 한 달 생활비
- `예시_구성.md` – 인포그래픽 구성 예시 (제목 → 핵심 숫자 3개 → 차트 → 출처)

## 🧭 기본 미션 (순서대로)
1. 데이터를 보고 **가장 말하고 싶은 숫자 3개**를 직접 고른다
2. 종이에 대충 배치를 그려 본다 (사진 찍어 Claude에게 보여 줘도 돼요)
3. Claude와 함께 HTML로 A4 세로 인포그래픽을 만든다
4. PNG와 PDF로 저장한다
5. 숫자가 원본 데이터와 맞는지 **직접 계산해서** 한 개 이상 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 아이콘이나 일러스트를 ChatGPT로 만들어 넣기
- 같은 데이터로 카드뉴스(08번) 버전도 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
data/1인가구_생활비.csv 에서 내가 고른 숫자 3개를 중심으로 A4 세로 인포그래픽을 HTML로 만들어 줘. 내가 그린 배치 사진(배치.jpg)을 참고해서.
```
