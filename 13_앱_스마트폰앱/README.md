# 13. 스마트폰 앱 만들기

> **얻는 능력:** 만든 것을 **휴대폰 홈 화면에서 앱처럼** 쓰게 만드는 능력

**왜 배우나요?** 사람들은 대부분 휴대폰으로 써요. 웹앱을 '설치 가능한 앱(PWA)'으로 만들면 앱스토어 없이도 홈 화면에 아이콘이 생겨요.

## 📁 들어 있는 파일
- `요구사항.md` – '오늘의 물 마시기 기록' 앱 요구사항
- `아이콘_만들기.md` – 앱 아이콘을 ChatGPT로 만드는 방법

## 🧭 기본 미션 (순서대로)
1. 요구사항을 읽고 화면 2개(기록, 통계)를 종이에 그린다
2. Claude와 함께 휴대폰 화면에 맞는 웹앱을 만든다 (기록은 휴대폰 안에 저장)
3. **PWA**로 만든다 (아이콘, 오프라인 동작)
4. 1단계 11번처럼 인터넷에 올리고, 휴대폰 사파리에서 '홈 화면에 추가'를 한다
5. 비행기 모드에서도 열리는지 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- **Expo**로 진짜 앱(React Native) 버전 만들기 → 휴대폰의 Expo Go 앱으로 실행
- 알림(리마인더) 기능 넣기
