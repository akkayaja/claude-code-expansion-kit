## 진행 방법
- 순서대로 해도 되고, **영역별로 골라서** 해도 돼요. 단, 같은 영역 안에서는 번호 순서를 지켜 주세요 (앞 실습 결과를 뒤에서 써요).
- 원칙은 1단계와 같아요: **먼저 직접 보고 추측 → Claude에게 묻기 → 내 눈으로 검증**
- 정답 파일이 있는 실습(02, 03, 06, 15, 16, 24)은 채점이 끝날 때까지 정답을 열지 않아요.
- 모든 데이터·음성·사진은 **가짜**예요. 회사 자료나 남의 개인정보로 연습하지 않아요.
