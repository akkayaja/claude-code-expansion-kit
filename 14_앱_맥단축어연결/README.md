# 14. 맥 단축어로 내 도구 부르기

> **얻는 능력:** 만든 스크립트를 **단축키·메뉴·음성으로 바로 실행**하게 만드는 능력

**왜 배우나요?** 좋은 도구도 터미널을 열어야 하면 안 쓰게 돼요. 단축어(Shortcuts)에 연결하면 버튼 한 번으로 실행돼요.

## 📁 들어 있는 파일
- `예시스크립트/오늘날짜폴더.py` – 오늘 날짜 폴더를 만들어 주는 간단한 스크립트
- `예시스크립트/클립보드정리.py` – 복사한 글의 빈 줄·공백을 정리하는 스크립트

## 🧭 기본 미션 (순서대로)
1. 두 스크립트를 터미널에서 직접 실행해 본다
2. 맥 '단축어' 앱에서 '셸 스크립트 실행' 동작으로 `클립보드정리.py`를 연결한다
3. 단축키(예: ⌃⌥C)를 지정하고 아무 앱에서나 써 본다
4. 메뉴 막대에서도 실행되게 한다
5. 1단계에서 만든 스크립트 하나를 골라 같은 방식으로 연결한다

## 🔥 도전 미션 (기본을 끝냈다면)
- Finder에서 파일을 우클릭 → '빠른 동작'으로 실행되게 만들기 (예: 선택한 이미지 크기 줄이기)
- Siri에게 말해서 실행하기
