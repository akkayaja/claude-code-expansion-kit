# 07. 썸네일 만들기 (ChatGPT 이미지 + 글자 얹기)

> **얻는 능력:** AI 그림과 코드를 섞어 **썸네일을 여러 안 빠르게** 만드는 능력

**왜 배우나요?** 썸네일은 클릭률을 정하는 가장 중요한 요소예요. 한 장을 오래 만드는 것보다 3~5안을 빨리 만들어 비교하는 게 이겨요.

## 📁 들어 있는 파일
- `공통도구/이미지만들기.sh` (ChatGPT로 그림 만들기)
- `예시_썸네일문구.md` – 01번 주제에 맞는 썸네일 문구 예시
- `template/썸네일틀.html` – 1280×720 썸네일 틀 (배경 그림 + 큰 글자)

## ⚠️ 알아 둘 것
ChatGPT 이미지 생성은 **내 ChatGPT 요금제 사용량**을 써요. 한 번에 너무 많이 만들지 마세요. 실존 인물·유명 캐릭터·브랜드 로고는 요청하지 않아요.

## 🧭 기본 미션 (순서대로)
1. `00_시작하기/README.md`의 **Codex 연결**을 먼저 끝낸다
2. 01번 대본 주제로 썸네일 문구 3개를 직접 쓴다 (7글자 이내 큰 글씨 + 작은 보조 문구)
3. `이미지만들기.sh`로 배경 그림 2장을 만든다 (글자 없는 그림으로 요청)
4. Claude와 함께 `썸네일틀.html`에 배경과 문구를 얹어 PNG로 저장한다 → **3안 완성**
5. 3안을 작게 줄여서(휴대폰 화면 크기) 나란히 놓고 가장 잘 읽히는 것을 고른다

## 🔥 도전 미션 (기본을 끝냈다면)
- 같은 배경에 문구만 바꾼 A/B 2안을 자동으로 10장 만들기
- 내 채널 '썸네일 규칙'(글꼴, 색, 위치)을 정해 CLAUDE.md에 적어 두기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
공통도구/이미지만들기.sh 로 유튜브 썸네일 배경 그림을 만들어 줘. 퇴근 후 책상에서 노트북으로 AI를 배우는 장면, 글자는 넣지 말고, 왼쪽은 비워 둬. 저장 이름은 bg1.png.
```
```
template/썸네일틀.html 에 bg1.png 를 배경으로 깔고 '퇴근 후 1시간' 문구를 크게 얹어서 1280x720 PNG로 저장해 줘. 문구 3안을 각각 다른 파일로.
```
