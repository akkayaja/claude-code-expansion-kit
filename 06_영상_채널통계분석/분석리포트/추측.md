# 잘 된 영상의 공통점 — 먼저 한 추측 (미션 1)

> 앞 20개 영상만 훑어보고 적은 추측이에요. (Claude가 대신 작성, 내가 확인)
> 미션 2에서 120개 전체 데이터로 맞는지 확인해요.

1. **형식**: 쇼츠가 롱폼보다 조회수가 높을 것 같다.
   - 근거: 20개 중 조회수 상위 5개 중 4개가 쇼츠였다.
2. **길이**: 롱폼은 길수록(15분 이상) 시청지속률이 떨어질 것 같다.
   - 근거: 1,305초·1,733초 영상의 지속률이 24~26%로 가장 낮았다.
3. **제목**: "따라하기 실습", "N가지만 알면 끝"처럼 구체적인 제목이 클릭률이 높을 것 같다.
   - 근거: 클릭률 1등(7.1%)이 "업무 자동화 5단계 따라하기 실습"이었다.

(덤) 요일은 주말(토·일)에 올린 영상이 더 잘 될 것 같다.
