# 06. 채널 통계 분석 (무엇이 잘 됐나)

> **얻는 능력:** 영상 성과 데이터에서 **다음에 무엇을 만들지** 근거를 찾는 능력

**왜 배우나요?** '감'이 아니라 숫자로 다음 콘텐츠를 정하는 사람이 채널을 키워요. 1단계 06번 분석 리포트를 콘텐츠에 적용해요.

## 📁 들어 있는 파일
- `data/채널_영상통계.csv` – 가상 채널의 영상 120개 (제목, 형식, 길이, 조회수, 클릭률, 시청 지속률, 업로드 요일)
- `정답_발견한패턴.md` – 데이터에 일부러 심어 둔 패턴 (**먼저 보지 마세요**)

## 🧭 기본 미션 (순서대로)
1. 데이터를 열어 보고 '잘 된 영상의 공통점'을 내가 먼저 3개 추측해 적는다
2. Claude와 함께 형식(쇼츠/롱폼), 길이, 제목 특징, 요일별로 비교한다
3. 그래프 3개 이상이 들어간 리포트를 만든다
4. '다음 달 만들 영상 3개'를 근거와 함께 제안한다
5. `정답_발견한패턴.md`와 비교해 몇 개를 찾았는지 센다

## 🔥 도전 미션 (기본을 끝냈다면)
- 제목 120개를 AI로 분류(질문형/숫자형/감탄형 등)해 클릭률 비교하기
- 1단계 08번처럼 대시보드로 만들기
