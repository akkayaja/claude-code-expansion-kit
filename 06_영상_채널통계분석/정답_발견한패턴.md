# 정답: 데이터에 심어 둔 패턴 4개

> 채점할 때만 보세요. (데이터에 무작위 잡음이 섞여 있어서 숫자는 조금 다를 수 있어요.)

1. **제목에 숫자가 들어가면 클릭률이 약 1.5%p 높다** ("5가지", "3단계" 등)
2. **롱폼은 8~12분 길이의 시청지속률이 가장 높다.** 20분 이상은 크게 떨어진다
3. **화요일·목요일 업로드 영상의 조회수가 다른 요일보다 약 1.4배 많다**
4. **'따라하기 실습' 롱폼의 조회수가 다른 롱폼의 약 2배다**

### 덤
- 쇼츠는 조회수 평균은 높지만 클릭률 영향이 롱폼과 비슷하다 → 쇼츠만 보고 판단하면 안 됨
- 날짜는 연습용으로 만든 값이라 실제 요일과 맞지 않아요. **'요일' 칸**을 기준으로 보세요.
