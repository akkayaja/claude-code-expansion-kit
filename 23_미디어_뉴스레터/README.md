# 23. 뉴스레터 만들고 보내기

> **얻는 능력:** 한 주의 내용을 **보기 좋은 메일 한 통**으로 만들어 보내는 능력

**왜 배우나요?** 뉴스레터는 구독자와 직접 연결되는 통로예요. 템플릿과 자동화를 만들어 두면 매주 보내는 부담이 줄어요.

## 📁 들어 있는 파일
- `이번주_재료.md` – 이번 주에 배운 것, 읽은 글, 만든 것 (예시)
- `template/뉴스레터틀.html` – 메일용 HTML 틀

## ⚠️ 알아 둘 것
다른 사람에게 보낼 때는 반드시 **받겠다고 동의한 사람**에게만, 수신 거부 방법을 넣어서 보내요 (정보통신망법).

## 🧭 기본 미션 (순서대로)
1. 재료를 보고 뉴스레터 구성(인사 → 이번 주 핵심 → 링크 3개 → 다음 주 예고)을 직접 정한다
2. Claude와 함께 재료.md를 넣으면 HTML 메일이 나오는 스크립트를 만든다
3. 1단계 03번에서 배운 방식으로 **나에게** 보내 본다
4. 휴대폰 메일 앱과 컴퓨터에서 깨지지 않는지 확인한다
5. 구독자 목록 관리는 실제 서비스(스티비, 메일침프 등)를 써야 하는 이유를 Claude에게 듣고 정리한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 22번 블로그 글이 올라오면 뉴스레터 재료에 자동으로 모이게 하기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
이번주_재료.md 를 template/뉴스레터틀.html 에 넣어서 메일용 HTML 을 만드는 스크립트를 짜 줘. 휴대폰 메일에서 깨지지 않게.
```
```
직접 만든 메일 보내기와 스티비 같은 서비스를 쓰는 것의 차이를 알려 줘. 스팸, 수신 거부, 개인정보 측면에서.
```
