# 21. 노코드 자동화 도구 (n8n)

> **얻는 능력:** 코드 대신 **블록을 이어서** 자동화를 만들고, 코드 방식과 비교하는 능력

**왜 배우나요?** 회사나 고객은 '코드'보다 '눈에 보이는 흐름도'를 더 편하게 여겨요. 노코드 도구를 다룰 줄 알면 남에게 넘겨주기(인수인계)가 쉬워져요.

## 📁 들어 있는 파일
- `만들흐름.md` – 만들 자동화: 'RSS 새 글 → AI 요약 → 텔레그램 알림'
- `비교표.md` – 코드 방식 vs 노코드 방식 비교 양식

## 🧭 기본 미션 (순서대로)
1. n8n을 내 컴퓨터에서 실행한다 (`npx n8n` → http://localhost:5678)
2. '매시간 실행 → RSS 읽기 → 새 글만 거르기' 흐름을 블록으로 만든다
3. 19번 텔레그램 봇으로 알림을 보낸다
4. 같은 기능을 파이썬 스크립트로도 만들어 본다 (Claude와 함께)
5. `비교표.md`를 채운다: 만드는 시간, 고치기 쉬움, 남에게 넘겨주기 쉬움

## 🔥 도전 미션 (기본을 끝냈다면)
- AI 요약 블록을 넣기 (API 키가 필요하면 비용 확인 후)
- n8n 흐름을 내보내기(JSON) 해서 저장소에 보관하기 (토큰이 들어 있지 않은지 확인!)
