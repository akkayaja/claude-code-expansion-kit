# 17. 번역과 다국어 만들기

> **얻는 능력:** 용어를 **일관되게 유지하며** 여러 언어 버전을 만드는 능력

**왜 배우나요?** AI 번역은 쉽지만 '같은 단어를 매번 다르게 번역하는' 문제가 생겨요. 용어집으로 일관성을 지키는 게 실무 번역의 핵심이에요.

## 📁 들어 있는 파일
- `data/카페_안내문.md` – 가상 카페 안내문 (메뉴, 이용 규칙)
- `data/용어집.csv` – 꼭 지켜야 할 번역어 (예: 아샷추 → Iced Tea with Espresso Shot)

## 🧭 기본 미션 (순서대로)
1. 안내문을 영어로 번역하되, **용어집을 지키도록** 지시한다
2. 용어집을 지켰는지 검사하는 스크립트를 만든다 (용어집 단어가 번역문에 들어 있는지)
3. 일본어·중국어(간체) 버전도 만든다
4. 1단계 11번 웹페이지에 언어 선택 버튼을 붙인다
5. 번역을 거꾸로(영어 → 한국어) 돌려 뜻이 바뀐 곳이 없는지 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 용어집을 지키지 않은 문장을 자동으로 다시 번역시키는 '검수 → 재번역' 흐름 만들기 (1단계 17번 응용)

막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
data/카페_안내문.md 를 영어로 번역해 줘. data/용어집.csv 의 번역어는 반드시 그대로 써.
```
```
번역문이 용어집을 지켰는지 검사하는 스크립트를 짜 줘. 안 지킨 곳을 표로.
```
