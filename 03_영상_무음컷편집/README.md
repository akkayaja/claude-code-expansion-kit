# 03. 무음 구간 자동 컷 편집

> **얻는 능력:** 영상에서 말이 없는 구간을 찾아 **자동으로 잘라내는** 능력 (ffmpeg)

**왜 배우나요?** 영상 편집에서 가장 지루한 일이 '음… 쉬는 구간 자르기'예요. 이걸 자동으로 하면 편집 시간이 크게 줄어요.

## 📁 들어 있는 파일
- `media/말사이공백.mp4` – 문장 사이에 1.5~3초씩 침묵이 있는 영상
- `정답_무음구간.csv` – 침묵이 있는 구간의 시작·끝 시각

## 🧭 기본 미션 (순서대로)
1. 영상을 직접 보며 '자르고 싶은 곳'을 대략 적어 본다
2. Claude와 함께 ffmpeg의 `silencedetect`로 무음 구간 목록을 뽑는다
3. 뽑은 목록을 `정답_무음구간.csv`와 비교한다
4. 무음 구간을 잘라낸 `말사이공백_컷.mp4`를 만든다
5. 원본과 결과의 **길이(초)**를 비교해 몇 % 줄었는지 적는다

## 🔥 도전 미션 (기본을 끝냈다면)
- 무음을 완전히 지우지 말고 0.3초씩 남겨서 자연스럽게 만들기
- 폴더 안 영상 여러 개를 한 번에 처리하는 스크립트로 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
ffmpeg로 media/말사이공백.mp4 의 무음 구간(1초 이상)을 찾아 표로 보여 줘. 명령어 옵션 하나하나 무슨 뜻인지도.
```
```
찾은 무음 구간을 잘라낸 영상을 만들어 줘. 말 앞뒤로 0.3초는 남겨 줘.
```
