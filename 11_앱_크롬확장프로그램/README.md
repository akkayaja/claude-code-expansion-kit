# 11. 크롬 확장 프로그램 만들기

> **얻는 능력:** 자주 쓰는 웹사이트에 **내가 원하는 기능을 덧붙이는** 능력

**왜 배우나요?** 매일 쓰는 사이트가 불편할 때, 사이트를 바꿀 순 없지만 내 브라우저에서는 바꿀 수 있어요. 크롬 확장은 HTML·JS 몇 개로 만들어요.

## 📁 들어 있는 파일
- `연습사이트/` – 가상 뉴스 사이트 (글 10개). 확장을 시험할 대상
- `요구사항.md` – 만들 기능 목록

## ⚠️ 알아 둘 것
인터넷에서 받은 확장 프로그램 코드를 그대로 설치하지 마세요. 내가 만든 것만, 무슨 권한을 쓰는지 알고 설치해요.

## 🧭 기본 미션 (순서대로)
1. 연습 사이트를 열어 보고(`python3 -m http.server 8770` → http://localhost:8770) 불편한 점을 직접 적는다
2. 기본 기능: 글 페이지에 **'읽는 데 걸리는 시간: 약 N분'**을 맨 위에 표시하는 확장을 만든다
3. 크롬 `chrome://extensions` → 개발자 모드 → '압축 해제된 확장 프로그램 로드'로 설치한다
4. 기능 추가: 툴바 버튼을 누르면 **현재 글을 3줄로 요약할 수 있게 본문을 복사**한다
5. 확장을 끄고 켜며 정상 동작을 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 내가 실제로 자주 쓰는 사이트용 확장 만들기 (개인정보가 오가는 사이트는 피하기)
- 광고·추천 영역 숨기기 같은 '집중 모드' 만들기
