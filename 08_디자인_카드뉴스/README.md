# 08. 카드뉴스 자동 만들기

> **얻는 능력:** 원고 하나로 **인스타용 카드뉴스 여러 장**을 한 번에 만드는 능력

**왜 배우나요?** 카드뉴스는 디자인 툴로 한 장씩 만들면 오래 걸려요. 틀을 한 번 만들어 두면 원고만 바꿔서 몇 초 만에 다시 뽑을 수 있어요.

## 📁 들어 있는 파일
- `원고/카드뉴스_원고.md` – 카드 8장 분량 원고 ('엑셀 자동화 전에 알아야 할 5가지')
- `template/카드틀.html` – 1080×1080 카드 틀

## 🧭 기본 미션 (순서대로)
1. 원고를 읽고 카드별로 **한 장에 한 메시지**인지 직접 확인하고 고친다
2. Claude와 함께 원고의 `---`를 기준으로 카드를 나눠 PNG 8장을 만드는 스크립트를 만든다
3. 표지·본문·마지막(행동 유도) 카드의 디자인을 다르게 한다
4. 휴대폰으로 옮겨 넘겨 보며 글자 크기를 확인한다
5. 원고 한 줄을 바꾸고 다시 실행해 **바뀐 카드만 다시 나오는지** 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 표지 그림만 07번처럼 ChatGPT로 만들기
- 1단계 실습 하나를 골라 카드뉴스로 소개하기 (포트폴리오용)
