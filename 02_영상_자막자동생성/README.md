# 02. 영상 자막 자동 만들기 (음성 인식)

> **얻는 능력:** 영상의 말소리를 글자로 받아 적어 **자막 파일(SRT)**로 만드는 능력

**왜 배우나요?** 자막은 손으로 달면 영상 길이의 5~10배 시간이 들어요. 자동으로 만들고 틀린 곳만 고치면 몇 분이면 끝나요. 회의록(15번)과 같은 기술이에요.

## 📁 들어 있는 파일
- `media/강의샘플.mp4` – 약 1분짜리 한국어 강의 영상 (맥 음성으로 만든 가짜 강의)
- `정답_대본.txt` – 영상에서 실제로 말한 문장 (비교용)

## ⚠️ 알아 둘 것
음성 인식 모델은 처음 받을 때 수백 MB~1GB 정도를 내려받아요. 와이파이에서 하세요.

## 🧭 기본 미션 (순서대로)
1. 영상을 직접 틀어 보고 내용을 확인한다
2. Claude에게 음성 인식 도구(예: `mlx-whisper`나 `faster-whisper`) 설치를 부탁하고, **무엇을 설치하는지** 설명을 듣는다
3. 영상에서 자막 파일 `강의샘플.srt`를 만든다
4. `정답_대본.txt`와 비교해 **틀린 글자 수**를 세어 본다
5. 틀린 곳을 고치고, 영상 플레이어(IINA, VLC 등)에서 자막이 맞게 나오는지 본다

## 🔥 도전 미션 (기본을 끝냈다면)
- 모델 크기(small, medium 등)를 바꿔 속도와 정확도를 비교하는 표 만들기
- 자막을 영상에 **입혀서**(번인) 새 영상으로 저장하기 (04번에서 다시 씀)
