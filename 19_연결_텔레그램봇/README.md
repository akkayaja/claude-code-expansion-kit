# 19. 텔레그램 봇 만들기

> **얻는 능력:** 휴대폰 메신저로 **알림을 받고 명령을 보내는** 봇을 만드는 능력

**왜 배우나요?** 메일보다 메신저 알림이 훨씬 빨리 보여요. 그리고 봇에게 말을 걸어 일을 시킬 수도 있어요. 텔레그램은 봇 만들기가 무료이고 쉬워요.

## 📁 들어 있는 파일
- `봇_기능목록.md` – 만들 명령어 목록 (/오늘, /날씨, /할일)
- `.env.example` – 봇 토큰을 넣을 자리 (실제 토큰은 .env에)

## ⚠️ 알아 둘 것
봇 토큰은 비밀번호와 같아요. `.env`에만 넣고, 화면 캡처나 GitHub에 절대 올리지 마세요.

## 🧭 기본 미션 (순서대로)
1. 휴대폰에 텔레그램을 설치하고, **BotFather**에게 봇을 만들어 토큰을 받는다 (**토큰은 직접** `.env`에 넣기)
2. 봇이 '안녕하세요'를 나에게 보내게 한다
3. `/할일` 명령을 보내면 1단계 14번 할일목록을 답하게 한다
4. 1단계 14번이나 옷차림 알림을 텔레그램으로도 받게 바꾼다
5. 봇이 **나에게만** 대답하게 막는다 (내 채팅 ID 확인)

## 🔥 도전 미션 (기본을 끝냈다면)
- 사진을 보내면 16번 OCR로 영수증을 읽어 답하게 하기
- 음성 메시지를 보내면 받아써서 답하게 하기
