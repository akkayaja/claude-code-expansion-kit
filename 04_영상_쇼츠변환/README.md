# 04. 가로 영상을 세로 쇼츠로 바꾸기

> **얻는 능력:** 16:9 영상을 **9:16 세로 쇼츠**로 바꾸고 자막을 크게 입히는 능력

**왜 배우나요?** 쇼츠·릴스는 세로 영상이에요. 긴 영상 하나에서 쇼츠 여러 개를 뽑아내는 게 요즘 채널 운영의 기본이에요.

## 📁 들어 있는 파일
- `media/가로영상.mp4` – 1920×1080 가로 영상 (02번과 같은 강의)
- 02번에서 만든 자막 파일 (없으면 `정답_자막.srt` 사용)

## 🧭 기본 미션 (순서대로)
1. 가로 영상에서 쇼츠로 쓸 **20~30초 구간**을 직접 고른다
2. 그 구간만 잘라낸다
3. 1080×1920 세로로 바꾼다 (가운데 자르기 또는 위아래 흐린 배경 넣기 중 선택)
4. 자막을 화면 아래쪽에 **크고 굵게** 입힌다
5. 휴대폰으로 옮겨서 실제로 보기 편한지 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 맨 위에 제목 띠(훅 문장) 넣기
- 한 번에 쇼츠 3개를 뽑는 스크립트 만들기 (구간 목록 CSV를 받아서)
