# 15. 회의 녹음 → 회의록 자동 만들기

> **얻는 능력:** 녹음 파일을 **받아쓰고, 요약하고, 할 일을 뽑는** 능력

**왜 배우나요?** 회의록은 어느 조직에나 있는 귀찮은 일이에요. 받아쓰기(02번 기술) + 요약(AI)을 엮으면 녹음만 하면 회의록이 나와요.

## 📁 들어 있는 파일
- `media/회의녹음.m4a` – 3명이 나누는 약 2분짜리 가상 회의 (맥 음성으로 만듦)
- `template/회의록_양식.md` – 회의록 양식
- `정답_할일목록.csv` – 회의에서 정해진 할 일 (담당자·마감)

## ⚠️ 알아 둘 것
실제 회사 회의 녹음은 외부 AI에 넣지 마세요. 연습은 이 가짜 녹음으로만 해요.

## 🧭 기본 미션 (순서대로)
1. 녹음을 직접 들으며 할 일을 메모해 본다
2. 02번 도구로 받아쓴다
3. 받아쓴 글을 Claude와 함께 회의록 양식(요약, 결정 사항, 할 일)으로 정리한다
4. 할 일 목록을 `정답_할일목록.csv`와 비교한다
5. 녹음 파일을 폴더에 넣기만 하면 회의록이 나오는 스크립트로 만든다

## 🔥 도전 미션 (기본을 끝냈다면)
- 말한 사람(화자)을 구분해 보기
- 회의록을 메일(1단계 03번)이나 텔레그램(19번)으로 자동 전송하기
