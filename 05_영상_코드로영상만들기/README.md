# 05. 코드로 영상 만들기 (데이터 애니메이션)

> **얻는 능력:** 편집 프로그램 없이 **코드(HTML)로 영상**을 만드는 능력

**왜 배우나요?** 숫자가 움직이는 그래프, 순위가 바뀌는 막대, 자막이 튀어나오는 정보 영상은 편집 프로그램보다 코드가 훨씬 빠르고 수정도 쉬워요.

## 📁 들어 있는 파일
- `data/도시별_카페수.csv` – 가상 도시 8곳의 연도별(2016~2025) 카페 수
- `예시_장면구성.md` – 30초 영상 장면 구성 예시

## 🧭 기본 미션 (순서대로)
1. `예시_장면구성.md`를 보고 내 영상의 장면 구성을 직접 적는다 (장면 3~5개)
2. Claude에게 HTML 기반 영상 도구(**HyperFrames** – 이 컴퓨터에 이미 설치돼 있어요, 또는 **Remotion**)로 만들자고 한다
3. 첫 장면(제목)만 먼저 만들어 미리보기로 확인한다
4. 데이터 장면(연도별 막대가 자라는 애니메이션)을 추가한다
5. mp4로 내보내고 길이·해상도를 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 같은 코드로 숫자 데이터만 바꿔 다른 주제 영상 만들기 (재사용성 확인)
- 18번에서 만든 목소리를 입히기
