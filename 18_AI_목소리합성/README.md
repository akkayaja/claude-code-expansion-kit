# 18. 대본을 목소리로 만들기 (TTS)

> **얻는 능력:** 글을 **자연스러운 음성 파일**로 바꾸고 영상에 입히는 능력

**왜 배우나요?** 얼굴이나 목소리를 드러내지 않고도 영상을 만들 수 있어요. 내레이션, 안내 방송, 오디오북에 다 쓰여요.

## 📁 들어 있는 파일
- `대본/내레이션.txt` – 30초 분량 내레이션 대본
- `발음_사전.csv` – 기계가 잘못 읽는 단어와 고쳐 읽을 표기 (예: AI → 에이아이)

## ⚠️ 알아 둘 것
다른 사람의 목소리를 흉내 내는 음성 복제는 하지 않아요. 내 목소리나 기본 제공 목소리만 써요.

## 🧭 기본 미션 (순서대로)
1. 맥 내장 음성(`say -v Yuna`)으로 대본을 읽혀 음성 파일을 만든다 (무료)
2. 들어 보고 **어색하게 읽는 단어**를 찾아 발음 사전에 추가한다
3. 발음 사전을 적용해 다시 만든다
4. 문장 사이 쉼(0.5초)을 넣어 자연스럽게 만든다
5. 05번이나 08번 결과물에 음성을 입혀 영상으로 만든다

- 배경음악을 작게 깔기 (저작권 없는 음원만)
