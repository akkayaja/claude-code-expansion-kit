# 09. 발표 슬라이드 자동 만들기

> **얻는 능력:** 글로 쓴 내용을 **발표 슬라이드(파워포인트)**로 바꾸는 능력

**왜 배우나요?** 보고·발표·강의는 어디서나 필요해요. 내용만 정리하면 슬라이드는 자동으로 나오게 만들 수 있어요.

## 📁 들어 있는 파일
- `내용/발표내용.md` – '우리 팀 업무 자동화 제안' 발표 내용 (가상)
- `template/슬라이드_규칙.md` – 한 장에 몇 줄, 글자 크기 등 규칙

## 🧭 기본 미션 (순서대로)
1. 발표내용.md를 읽고 **슬라이드 1장 = 메시지 1개**로 직접 나눠 본다 (목표 8~10장)
2. Claude와 함께 파이썬(`python-pptx`)으로 .pptx 파일을 만든다
3. 키노트나 파워포인트에서 열어 깨진 곳이 없는지 본다
4. 숫자가 있는 장 하나는 **차트**로 바꾼다
5. 슬라이드 규칙을 지켰는지 Claude에게 점검시킨다

## 🔥 도전 미션 (기본을 끝냈다면)
- 같은 내용으로 HTML 슬라이드(브라우저 발표용)도 만들어 비교하기
- 발표 대본(발표자 노트)도 각 장에 자동으로 넣기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 보고, 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.**

```
내용/발표내용.md 를 template/슬라이드_규칙.md 에 맞춰 python-pptx 로 10장 이내 .pptx 로 만들어 줘. 숫자가 있는 장은 차트로.
```
