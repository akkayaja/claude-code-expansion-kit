# 22. 블로그 만들고 자동으로 글 올리기

> **얻는 능력:** 마크다운 글을 쓰면 **블로그에 자동으로 올라가는** 체계를 만드는 능력

**왜 배우나요?** 학습 기록과 사례 정리를 블로그로 공개하면 검색으로 사람이 찾아와요. 포트폴리오의 집이 생기는 거예요.

## 📁 들어 있는 파일
- `글/` – 예시 글 3개 (마크다운)
- `블로그_구성.md` – 블로그 메뉴와 글 형식

## 🧭 기본 미션 (순서대로)
1. Claude와 함께 정적 블로그(예: Astro, Hugo, Jekyll 중 추천받기)를 만든다
2. `글/`의 예시 3개가 블로그에 나오게 한다
3. GitHub Pages나 Vercel로 인터넷에 올린다 (1단계 11번 복습)
4. 새 글 md 파일을 넣고 `git push`만 하면 **자동으로 올라가게** 만든다
5. 1단계 학습일지 하나를 블로그 글로 다듬어 올린다 (개인정보 확인!)

## 🔥 도전 미션 (기본을 끝냈다면)
- 글마다 대표 이미지를 07번 방식으로 자동 생성하기
- 새 글이 올라가면 19번 텔레그램으로 알림 받기
