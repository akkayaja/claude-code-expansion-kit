# 01. 영상 대본 만들기 (롱폼 → 쇼츠 3개)

> **얻는 능력:** 주제 하나로 긴 영상 대본과 쇼츠 대본을 함께 뽑는 능력 (콘텐츠 기획)

**왜 배우나요?** 유튜브는 결국 **대본**이에요. 같은 주제로 10분짜리 하나와 60초짜리 여러 개를 만들 줄 알면 콘텐츠 양이 몇 배가 돼요.

## 📁 들어 있는 파일
- `data/주제후보.csv` – 가상의 채널 '퇴근 후 AI' 주제 후보 12개
- `template/대본_양식.md` – 훅·본론·마무리 칸이 있는 대본 양식
- `template/쇼츠_양식.md` – 60초 쇼츠 대본 양식 (초 단위)

## 🧭 기본 미션 (순서대로)
1. 주제후보 12개 중 '내가 클릭할 것 같은' 3개를 직접 고르고 이유를 적는다
2. Claude와 함께 그중 하나로 **8~10분 롱폼 대본**을 `대본_양식.md`에 맞춰 쓴다
3. 대본을 소리 내 읽으며 시간을 재 본다 (1분에 약 300자)
4. 롱폼 대본에서 **쇼츠 3개**를 뽑는다. 각 쇼츠는 첫 3초 훅이 달라야 한다
5. 제목 후보 10개를 만들고, 내가 고른 1개와 이유를 적는다

## 🔥 도전 미션 (기본을 끝냈다면)
- 같은 대본을 '초보자용'과 '실무자용' 두 버전으로 바꿔 보기
- 15번 프롬프트 템플릿처럼 '대본 만들기 템플릿'을 만들어 다음 주제에 재사용하기

```
data/주제후보.csv 에서 내가 고른 3번 주제로 8분짜리 유튜브 대본을 template/대본_양식.md 형식으로 써 줘. 첫 15초 훅을 3가지 버전으로 줘.
```
```

```
