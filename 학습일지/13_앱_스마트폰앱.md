## 💡 새 개념

- **PWA = 웹사이트에 앱 옷을 입힌 것**: HTML 한 장에 **신분증(manifest)**과 **보관 담당(서비스 워커)**만 더하면, 앱스토어 없이 홈 화면 아이콘이 생기고 인터넷 없이도 열린다
- **서비스 워커 = 휴대폰 안 보관함 관리인**: 처음 열 때 파일을 담아 두고, 다음부터는 인터넷보다 보관함을 먼저 본다. 그래서 비행기 모드에서도 열린다. 앱을 고치면 보관함 이름(v1→v2)을 바꿔야 새 파일로 갈아 끼운다
- **https가 있어야 설치된다**: 휴대폰에서 '홈 화면에 추가'하려면 인터넷 주소가 필요해서 12번에서 켠 GitHub Pages를 다시 썼다
- **홈 화면 앱과 사파리는 기록 칸이 따로**: 같은 주소라도 저장소가 달라서, 홈 화면 아이콘으로만 쓰기로 했다
- **PWA vs 일반 앱**: PWA는 심사·비용 없이 바로 배포되고 고치기 쉽지만, 앱이 닫혀 있을 때 알림 같은 휴대폰 기능에 제한이 있다. 일반 앱은 거의 다 되지만 앱스토어 심사와 개발자 등록비가 든다
- **React Native = 휴대폰 전용 부품으로 짓는 앱**: HTML `<div>` → `<View>`, 글자 → `<Text>`, 버튼 → `<Pressable>`. 저장도 localStorage 대신 AsyncStorage를 쓴다
- **Expo Go = 연습용 무대**: 내 앱이 Expo Go 안에서 잠깐 공연하는 것이지, 내 이름으로 된 앱이 설치되는 건 아니다. 아이폰에 독립 앱으로 깔려면 애플의 허가(서명)가 필요하다. 무료 방법(Xcode)은 7일마다 다시 설치해야 하고, 유료 방법은 연 99달러다
- **개발 서버 = 맥이 방송국**: `npx expo start`를 켜 두는 동안만 휴대폰이 앱을 받아 간다. 같은 포트(8081)를 이미 쓰고 있으면 다른 포트(8082)로 열자고 물어본다
- **터미널의 `!`는 '예전 명령 불러오기'**: zsh에서 `!cd`를 치면 예전에 친 cd 명령이 다시 실행돼 엉뚱한 폴더로 갔다. 채팅창의 `!` 명령은 터미널 탭마다 위치가 달라서, 실행 전에 `pwd`로 위치부터 보는 게 안전하다

## 📝 포트폴리오 한 줄

- **문제:** 사람들은 대부분 휴대폰으로 쓰는데, 내가 만든 웹페이지는 주소를 쳐야만 열리고 인터넷이 없으면 안 열렸다
- **해결:** '오늘의 물 마시기' 웹앱을 PWA(신분증 + 보관 담당 + 아이콘)로 만들어 GitHub Pages에 올리고 아이폰 홈 화면에 설치했다. 리마인더 카드와 아이콘 숫자를 더했고, 같은 앱을 Expo(React Native)로도 만들어 Expo Go에서 실행했다
- **효과:** 앱스토어 없이 홈 화면 아이콘으로 열리고 비행기 모드에서도 동작하는 앱이 생겼고, PWA와 진짜 앱의 차이(설치·알림·비용)를 직접 겪어서 설명할 수 있게 됐다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 처음엔 "사이트만 만든 거 아니야?"라는 생각이 들었다. PWA는 결국 웹사이트지만 홈 화면에 아이콘이 생기고 비행기 모드에서도 열려서, 쓰는 사람 입장에선 앱처럼 느껴진다는 걸 알았다.
- Expo로 진짜 앱 코드도 돌려 봤는데, 코드보다 계정 로그인·서버·포트 같은 준비 과정이 더 길었다. 아이폰에 내 앱을 깔려면 애플 허가가 필요하다는 것도 처음 알았다.
- 이번 앱은 실제로 쓰지 않기로 하고 정리했다. 그래도 "웹앱 → 설치 가능한 앱 → 진짜 앱"이 어떻게 다른지 직접 겪어 봐서, 나중에 앱을 만들 때 어떤 방식을 고를지 판단할 수 있을 것 같다.
