- **얻은 능력:** 주제 하나로 **긴 영상 대본과 쇼츠 대본을 함께 뽑는** 콘텐츠 기획 능력
- **만든 파일:** (모두 `01_영상_대본과쇼츠/결과/` — GitHub에는 올리지 않음)

  - `2_롱폼대본.md` — "코딩 몰라도 되는 업무 자동화 3가지" 8분 대본 (훅 3버전)
  - `3_쇼츠3개.md` — 롱폼 본론 1·2·3을 하나씩 자른 60초 쇼츠 3개

## 🔢 확인된 숫자

- 롱폼 말하는 부분: 첫 초안 **1,780자(약 6분)** → 본론마다 한 문단 보태서 **2,342자(약 7.8분)** (공백 포함, 1분 300자 기준)
- 쇼츠 길이: 1번 **271자(약 54초)**, 2번 처음 **340자(68초)** → 줄여서 **299자(60초)**, 3번 **276자(약 55초)**
- 제목 후보 **10개** 중 **1개** 선택

## 💡 새 개념

- **롱폼 → 쇼츠** — 국 한 솥을 끓여 작은 그릇 여러 개에 나눠 담기. 처음부터 "3가지"처럼 나뉜 주제를 고르면 쇼츠로 자르기 쉽다
- **훅(첫 3초·15초)** — 끝까지 볼 이유를 주는 부분. 숫자로 놀라게 / 질문으로 찌르기 / 오해 깨기 / 공감 장면 등 방식이 여러 가지
- **글자 수로 길이 재기** — 말하는 속도 1분 약 300자. 쓰고 나서 세어 보면 길이가 맞는지 바로 안다
- **쇼츠는 혼자 완결돼야 한다** — 롱폼을 안 본 사람도 그 한 편으로 이해되는지 체크
- **제목 = 훅과 같은 이야기** — 고른 제목(2시간 → 30초)이 롱폼 훅 A와 이어져서, 클릭하고 들어온 사람이 바로 이어 본다

## 📝 포트폴리오 한 줄

- **문제:** 주제 하나로 영상 하나만 만들면 콘텐츠 양이 늘지 않는다
- **해결:** Claude Code와 롱폼 대본(8분)을 쓰고, 본론을 하나씩 잘라 첫 3초 훅이 다른 쇼츠 3개와 제목 후보 10개를 만들었다
- **효과:** 주제 하나에서 영상 4편(롱폼 1 + 쇼츠 3) 분량의 대본을 한 번에 기획

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 대본 하나를 잘 나눠 두니 쇼츠 3개가 그대로 나와서, 처음 주제를 고를 때부터 '나눠 쓸 수 있는지'를 보는 게 중요하다는 걸 알았다.
- 제목을 직접 골라 보니 "빨라진다"보다 "2시간 → 30초"처럼 숫자로 보여 주는 쪽에 손이 갔다.
