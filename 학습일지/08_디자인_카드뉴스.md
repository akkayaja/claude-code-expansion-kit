## 💡 새 개념

- **도장 찍기(틀 + 원고)**: 디자인(틀)과 내용(원고)을 나누면, 원고만 바꿔 몇 장이든 다시 찍을 수 있다. 장수가 8장에서 9장으로 바뀌어도 번호(`01 / 09`)가 알아서 맞춰진다
- **`---`로 장 나누기**: 원고 안의 `---` 줄이 "여기서 다음 장으로 넘겨요"라는 표시다
- **한 장에 한 메시지**: 마지막 장에서 "저장도 하고 공유도 해 주세요"처럼 두 가지를 부탁하면 둘 다 안 하기 쉽다. 행동 유도는 하나만
- **`word-break: keep-all`**: 웹 페이지는 한글을 글자 하나 단위로 자를 수 있어서 "마세 / 요"처럼 잘린다. 이 설정 한 줄로 단어째로 줄을 바꾼다
- **바뀐 것만 다시 만들기**: 지난번 HTML과 글자 하나까지 비교해서 같으면 건너뛴다. 게임에서 이미 깬 스테이지는 건너뛰는 것과 같다
- **상대 경로와 절대 경로**: `결과/챗봇/…`처럼 짧게 적은 위치(상대 경로)는 크롬이 못 알아들어서, 스크립트가 전체 주소(절대 경로)로 바꿔 주게 고쳤다
- **그림 있으면 쓰고, 없으면 기본값**: 폴더에 `표지배경.png`가 있으면 표지에 깔고, 없으면 남색 표지를 쓴다

## 📝 포트폴리오 한 줄

- **문제:** 카드뉴스를 디자인 툴로 한 장씩 만들면 오래 걸리고, 문장 하나만 고쳐도 다시 손봐야 한다
- **해결:** 원고(`---`로 장 나누기)와 HTML 틀(표지·본문·마지막 3종)을 나누고, 파이썬 + 크롬 화면 캡처로 1080×1080 PNG를 자동 생성했다. 원고가 바뀐 카드만 다시 만들고, 표지 그림은 ChatGPT로 만들어 깔았다
- **효과:** 명령어 한 줄로 몇 초 만에 카드 8장 완성. 원고 한 줄을 고치면 그 1장만 다시 나오고, 같은 도구로 원고만 바꿔 1단계 실습 소개 카드뉴스 9장도 만들었다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 처음 8장은 몇 초 만에 나왔는데, 직접 보니 "마세 / 요"처럼 단어가 잘려 있었다. 자동으로 만들어도 결과는 꼭 내 눈으로 봐야 한다.
- 디자인을 정하고 나니 챗봇 카드뉴스는 원고만 써서 바로 만들 수 있었다. 틀을 한 번 잘 만들어 두는 게 핵심이다.
- 원고 한 줄을 바꿨더니 1장만 새로 나와서 신기했다. 장수가 많아지면 더 쓸모 있을 것 같다.
