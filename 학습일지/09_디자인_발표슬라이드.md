# 09. 발표 슬라이드 자동 만들기 — 학습일지

- **실습 날짜:** 2026-11-24
- **얻은 능력:** 글로 쓴 발표 내용(원고)을 **편집할 수 있는 파워포인트(.pptx)**로 자동으로 바꾸는 능력. 숫자는 진짜 차트로, 대본은 발표자 노트로 넣고, 완성된 파일을 다시 열어 **슬라이드 규칙을 자동 점검**하는 능력. 같은 원고로 **브라우저용 HTML 슬라이드**도 만드는 능력
- **만든 파일:**
  - `09_디자인_발표슬라이드/발표슬라이드코드/`: GitHub에 올리는 코드 (Claude가 만들고, 내가 확인)
    - `슬라이드원고.md`: 발표내용.md를 10장으로 나눈 원고. `---`로 장 나누기, `종류:`로 모양 고르기, `>`로 대본 쓰기
    - `슬라이드만들기.py`: 원고를 읽어 python-pptx로 .pptx를 만듦 (표지·본문·단계·표·차트·마지막 6가지 모양)
    - `규칙점검.py`: 완성된 .pptx를 다시 열어 글자 크기·줄 수·한 줄 글자 수·색 개수·차트 유무를 잼
    - `HTML슬라이드만들기.py`: 같은 원고로 HTML 슬라이드 1개 파일 + 장별 캡처
  - `09_디자인_발표슬라이드/발표슬라이드결과/`: GitHub에 올리는 결과 사본
    - `업무자동화_제안.pptx`: 10장, 8장 차트, 모든 장에 발표자 노트
    - `업무자동화_제안.html`: 브라우저 발표용 (→ 다음, F 전체 화면, N 대본)
    - `HTML슬라이드_한눈에보기.jpg`: HTML 슬라이드 10장을 한 장에 모아 본 것
  - (원본과 장별 캡처 PNG는 `09_디자인_발표슬라이드/결과/`에 있고, GitHub에는 올리지 않음)
  - 파이썬 라이브러리 `python-pptx`를 09 폴더 `.venv`에 설치 (`uv venv`, `uv pip install python-pptx`)

## 🔢 확인된 숫자

| 항목 | 숫자 |
|---|---|
| 슬라이드 장 수 | **10장** (목표 8~10) |
| 글자 크기 | 제목 40pt (표지 54, 마지막 48) / 본문 28pt / 차트 24pt |
| 본문 줄 수 | 장마다 **3줄 이하**, 가장 긴 줄 22자 |
| 쓰인 색 | **2가지**: 남색 `#1E2A3A` + 주황 `#F28C28` (흰 바탕 제외) |
| 차트 | **1개** (1~4월 기존 방식 vs 자동화 후 묶은 막대) |
| 규칙 위반 | **0건** |
| 발표 대본 | 장마다 52~104자, 합계 약 750자 → 약 2~3분 분량 |
| 파일 크기 | pptx **62KB** / HTML **10KB** |
| 1/6 계산 | 4월 기존 방식 12시간 ÷ 자동화 후 2시간 = 6배 감소 |

## 💡 새 개념

- **python-pptx**: 파이썬으로 파워포인트 파일을 만드는 부품 상자. 그림(PNG)이 아니라 **열어서 고칠 수 있는** 슬라이드가 나온다
- **제목 = 결론**: "문제", "기대 효과" 같은 이름표 대신 "주 3시간이 30분으로 준다"처럼 문장으로 쓰면, 제목만 넘겨 봐도 발표 전체가 이해된다
- **진짜 차트 vs 그림 차트**: python-pptx 차트는 파워포인트 안에서 클릭하면 숫자를 고칠 수 있다 (안에 작은 엑셀 표가 들어 있음)
- **원고 하나, 결과물 둘**: 같은 원고에서 pptx(회사 보고용)와 HTML(링크 공유·움직임용)을 둘 다 뽑았다. 08 카드뉴스의 "틀 + 원고" 도장 찍기와 같은 생각
- **발표자 노트**: 원고에 `>`로 쓴 줄이 슬라이드 아래 메모 칸에 들어간다. 발표자 보기에서는 나만 보인다
- **자동 점검의 빈틈**: 점검 코드가 "위반 0건"이라고 해도 차트 속 글자는 재지 못했다. 자동 점검 + 사람 눈 확인을 같이 해야 한다
- **`/`로 줄바꿈 위치 정하기**: 화살표 상자 안 글이 "공유 / 폴더에 지점 파일"처럼 어색하게 끊겨서, 원고에 `/`를 넣으면 그 자리에서 줄이 바뀌게 했다

## 📝 포트폴리오 한 줄

- **문제:** 보고·발표 자료를 파워포인트로 한 장씩 만들면 오래 걸리고, 글자 크기·줄 수·색 같은 규칙을 지켰는지 일일이 확인하기 어렵다
- **해결:** 발표 내용을 "1장 = 메시지 1개" 원고로 나누고, python-pptx로 표지·본문·단계·차트·마지막 장을 자동 생성했다. 대본은 발표자 노트로 넣고, 완성 파일을 다시 열어 규칙을 재는 점검 코드도 만들었다. 같은 원고로 HTML 슬라이드도 뽑았다
- **효과:** 명령어 한 줄로 10장 발표 파일 완성, 규칙 위반 0건. 원고에서 단어 하나(`표` → `차트`)만 바꿔 표를 편집 가능한 차트로 바꿨고, 한 원고로 pptx와 HTML 두 형식을 만들었다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 카드뉴스는 그림이라 고치려면 다시 만들어야 했는데, 파워포인트는 만든 뒤에도 열어서 바로 고칠 수 있었다. 남에게 넘겨줄 보고 자료는 pptx가 낫겠다.
- 원고에서 `표`를 `차트`로 한 단어만 바꿨는데 진짜 차트가 생겨서 신기했다. 내용과 모양을 나눠 두니 바꾸기가 쉽다.
- 점검 코드가 "위반 0건"이라고 해도 차트 글자는 놓쳤다. 자동 점검을 믿되, 마지막엔 내 눈으로 한 번 더 봐야 한다.
