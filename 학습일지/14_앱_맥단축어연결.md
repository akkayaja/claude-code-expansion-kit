# 14. 맥 단축어로 내 도구 부르기 — 학습일지

- **실습 날짜:** 2026-11-24
- **얻은 능력:** 파이썬 스크립트를 터미널에서 직접 돌리고 결과 숫자를 읽는 능력. 단축어 앱에 연결하는 방법은 알아 두었지만, 쓸 일이 없어서 연결은 건너뜀
- **만든 파일:** 없음 (예시 스크립트를 그대로 실행만 함. 바탕화면에 `2026-11-24` 빈 폴더가 생김)

## ✅ 한 일

| 미션 | 내용 | 상태 |
|---|---|---|
| 1 | 두 스크립트(`오늘날짜폴더.py`, `클립보드정리.py`)를 터미널에서 직접 실행 | 완료 |
| 2~5 | 단축어 앱 연결, 단축키, 메뉴 막대, 1단계 스크립트 연결 | **건너뜀**: 지금 매일 돌리는 스크립트가 없어서 연결해도 안 쓸 것 같았음 |

## 🔢 확인된 숫자

| 항목 | 숫자 | 기준 |
|---|---|---|
| 날짜 폴더 | 2번 실행해도 폴더 **1개** | 이미 있으면 새로 만들지 않고 열기만 함 |
| 클립보드 정리 | **47자 → 30자** | 띄어쓰기·줄바꿈도 한 글자로 셈. 겹친 공백과 빈 줄이 사라짐 |
| 정리된 글 다시 정리 | **30자 → 30자** | 더 지울 게 없음 |
| 처음 두 번 실행 | **0자 → 0자** | 클립보드가 비어 있었음. 스크립트가 빈 글을 다시 써 넣어서 계속 0자 |

## 💡 새 개념

- **클립보드 도구는 '복사 → 실행 → 붙여넣기' 순서가 생명**: 이 스크립트는 정리한 결과로 클립보드를 **덮어쓴다**. 복사를 안 하고 실행하면 빈 글이 들어가서 계속 0자가 나온다
- **같은 결과가 나오는 도구는 여러 번 눌러도 안전하다**: 날짜 폴더 스크립트는 몇 번을 실행해도 폴더가 하나뿐이라, 단축키에 붙이기 좋은 종류다
- **단축어 = 매크로 슬롯**: 나중에 매일 쓰는 스크립트가 생기면, 단축어 앱 → '셸 스크립트 실행'에 `/usr/bin/python3 "파일 위치"` 한 줄만 넣으면 된다. 폴더 이름에 띄어쓰기가 있으면 따옴표로 감싸고, 처음 한 번 설정 → 고급 → '스크립트 실행 허용'을 켜야 한다
- **필요 없는 건 안 하는 것도 판단이다**: 13의 물 앱처럼, 쓰지 않을 도구는 만들지 않기로 했다

## 📝 포트폴리오 한 줄

- **문제:** 만든 스크립트를 쓰려면 매번 터미널을 열어야 한다
- **해결:** 예시 스크립트를 직접 돌려 동작과 결과 숫자(47자→30자)를 확인하고, 단축어 연결 방법을 익혀 두었다
- **효과:** 매일 쓰는 스크립트가 생기면 바로 단축키로 연결할 수 있다. 쓸 일이 없는 지금은 연결하지 않기로 판단했다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 클립보드가 비어서 0자가 나왔을 때 처음엔 고장인 줄 알았다. 스크립트가 클립보드를 덮어쓴다는 걸 알고 나니 이해가 됐다.
- 단축키로 부르는 건 편해 보이지만, 지금은 매일 돌리는 스크립트가 없어서 굳이 만들지 않았다. 필요해지면 그때 한 줄만 넣으면 된다.
