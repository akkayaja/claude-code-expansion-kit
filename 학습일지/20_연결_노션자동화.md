# 20. 노션 자동화 — 학습일지

- **실습 날짜:** 2026-11-24
- **얻은 능력:** 노션 데이터베이스에 **코드로 기록을 쌓고(쓰기) 기간별로 골라 읽어(읽기) 요약**하는 능력, 그리고 Claude Code에 노션 MCP를 연결해 **말로** 노션을 다루는 능력
- **만든 파일:**
  - 코드 (`20_연결_노션자동화/노션코드/`, GitHub에 올림). 파이썬 기본 기능(urllib)만 써서 설치한 것 없음
    - `노션도구.py`: 공용 도구. .env에서 토큰 꺼내기, API 부르기, 429면 한 번 쉬었다 다시, 오류에서 토큰 가리기, 데이터베이스 자동 찾기
    - `1_칸만들기.py`: 설계도(`학습기록_DB구조.md`)대로 칸 7개 만들기 ('이름' → '제목' 이름 바꾸기 + 6칸 추가, 여러 번 실행해도 안전)
    - `2_한줄추가.py`: 기록 한 줄 추가 (같은 제목이면 안 넣음)
    - `3_학습일지옮기기.py`: 1단계 `학습일지/*.md` 21개를 읽어 한꺼번에 넣기, `--미리보기`, 중복 방지
    - `4_이번주요약.py`: 이번 주(월~일) 또는 `--7일` 기록만 노션에서 골라 와 요약 → `결과/요약_*.md`
    - `5_텔레그램메모봇.py`: (도전 B) 19번 텔레그램 봇으로 보낸 메모를 노션 학습기록에 저장 (키트='메모', 나에게만)
  - 노션 (내 워크스페이스): '학습기록' 페이지 안 표 (22줄), 연결 '학습기록봇'(API 토큰, 학습기록 페이지만 허용)
  - Claude Code 설정: 확장키트 폴더에 노션 MCP(`mcp.notion.com`) 연결 (local 설정)
  - 비밀 (`20_연결_노션자동화/.env`, GitHub에 올리지 않음): 노션 토큰

## 💡 새 개념

- **노션 = 여럿이 쓰는 만능 메모장 + 모양을 바꿔 볼 수 있는 똑똑한 표**: 글·표·사진·링크를 한 페이지에, 페이지 안에 페이지(책 속의 책). 표(데이터베이스)는 칸마다 종류가 정해져 있고 표·달력·보드로 바꿔 볼 수 있음. 표의 한 줄도 열면 페이지
- **API 토큰 vs OAuth**: API 토큰 = 내 집 열쇠 한 개 복사(나만 씀). OAuth = 손님마다 출입증 발급(공개 앱용). 그래서 API 토큰을 고름
- **연결은 했어도 문은 따로 열어 줘야 함**: 토큰만 있으면 아무 페이지도 못 봄. '콘텐츠 사용 권한'에서 학습기록 페이지만 허용 → 일기·독서 리스트는 못 봄 (최소 권한)
- **노션 MCP는 범위가 더 넓다**: 내 계정으로 로그인하는 방식이라 페이지를 고르는 단계 없이 내가 볼 수 있는 페이지 전체에 접근. 필요 없으면 노션 설정 '연결'에서 끊기
- **중복 방지 = 넣기 전에 먼저 물어보기**: 표에 있는 제목을 다 읽어 오고 없는 것만 넣음. 그래서 몇 번을 실행해도 안전
- **"이번 주"도 기준이 필요하다**: 달력 기준은 1개, 지난 7일은 14개. MCP Claude도 "날짜 칸 기준인지, 만든 날짜 기준인지" 밝힘 (만든 날짜로 보면 모두 11/24)
- **전선과 스위치**: 노션과 Claude는 연결됐지만 지금은 내가 시킬 때만 들어감. 진짜 자동은 예약(launchd)·커밋 훅·텔레그램 같은 '스위치'를 하나 더 달아야 함
- **두 연결 이어 붙이기**: 텔레그램(받기) + 노션(쌓기) 도구를 한 파일에서 같이 불러 씀. 휴대폰 한 줄 → 노션 카드 한 장
- **코드는 GitHub, 기록은 노션**: 노션에는 무엇을 배웠는지, 코드는 깃허브 링크 칸으로 연결

## 📝 포트폴리오 한 줄

- **문제:** 학습 기록이 md 파일 21개로 흩어져 있어 한눈에 보거나 기간별로 모아 보기 어렵다
- **해결:** 노션 API로 학습기록 데이터베이스의 칸을 만들고, md 학습일지를 읽어 중복 없이 한꺼번에 옮기고, 기간별로 골라 요약하는 스크립트를 만들었다. Claude Code에 노션 MCP를 연결해 말로도 조회했다
- **효과:** 21개 기록을 한 번에 옮김(다시 실행해도 0개 중복), 지난 7일 14개 기록을 자동 요약, 말로 물은 답(8개)이 코드 결과와 일치
