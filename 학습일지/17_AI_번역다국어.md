## 💡 새 개념

- **용어집 = 게임 아이템 이름표**: 같은 아이템을 퀘스트마다 다른 이름으로 부르면 헷갈린다. 번역도 정해진 이름표를 붙여야 메뉴판·홈페이지·영수증이 다 같은 말이 된다
- **검사기도 시험해야 한다 (연기 감지기 시험 버튼)**: 통과만 보면 검사기가 고장 나서 무조건 ✅를 주는 건지 알 수 없다. 일부러 틀린 본을 넣어 ❌가 뜨는지 확인했다
- **역번역은 다른 사람에게**: 번역한 사람이 거꾸로 번역하면 원문을 알고 있어서 틀린 곳을 머릿속으로 메운다. 원문을 못 본 도우미에게 맡기니 중국어에만 붙은 "최소(至少)"가 드러났다
- **검사기는 "이름표"만 보고, 역번역은 "뜻"을 본다**: 용어집 검사는 7/7이었지만, 역번역을 하니 용어집 자체의 선택(冰红茶 = 홍차로 좁혀짐, 春日咖啡 = 소리가 아닌 뜻으로 지은 이름)까지 보였다
- **언어팩 방식**: 페이지 글을 따로 쓰지 않고 검사를 통과한 번역 파일을 읽어서 끼웠다. 번역을 고치면 스크립트만 다시 돌리면 된다
- **세는 건 코드, 쓰는 건 AI**: 검수(글자가 있나?)는 코드가 정확하게, 재번역(자연스러운 문장)은 AI가. 1단계 17번에서 배운 역할 나누기를 번역에 그대로 썼다
- **줄 전체 재번역의 부작용**: 틀린 이름만이 아니라 줄 전체를 다시 번역해서 멀쩡하던 설명 표현도 바뀌었다. 그래서 마지막엔 사람이 한 번 훑어보는 게 좋다

## 📝 포트폴리오 한 줄

- **문제:** AI로 여러 언어 번역을 만들면 같은 메뉴 이름이 문서마다 다르게 번역되고, 누가 일일이 확인하기 어렵다
- **해결:** 용어집을 기준으로 영어·일본어·중국어 번역을 만들고, 용어집 준수를 코드로 검사한 뒤 안 지킨 줄만 Claude API로 자동 재번역하는 흐름과 언어 선택 버튼이 달린 웹페이지를 만들었다
- **효과:** 3개 언어 모두 용어집 7/7, 일부러 틀린 2곳을 9초 안에 자동으로 고쳐 다시 7/7. 역번역으로 뜻이 크게 바뀐 곳 0곳을 확인했다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 번역 자체보다 "같은 말을 같게 쓰는지 확인하는 것"이 실무 번역의 핵심이라는 게 와닿았다.
- 검사기가 7/7이라고 해도 끝이 아니었다. 역번역을 하니 용어집이 고른 말 자체의 문제까지 보여서, 확인 방법을 여러 개 겹치는 게 중요하다고 느꼈다.
- 1단계 11번(웹페이지)과 17번(검수 루프)을 다시 꺼내 쓰니, 배운 것들이 이어져 하나의 번역 도구가 되었다.
