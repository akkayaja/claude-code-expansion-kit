# 10. 데이터로 인포그래픽 포스터 만들기 — 학습일지

- **실습 날짜:** 2026-11-24
- **얻은 능력:** 숫자 데이터(CSV)에서 **말하고 싶은 숫자 3개**를 골라, A4 세로 **한 장짜리 인포그래픽**(PNG·PDF)으로 만드는 능력. 숫자는 손으로 적지 않고 코드가 데이터에서 직접 계산해 넣게 하는 능력. 같은 데이터로 카드뉴스 버전도 만드는 능력
- **만든 파일:**
  - `10_디자인_인포그래픽/인포그래픽코드/`: GitHub에 올리는 코드 (Claude가 만들고, 내가 확인)
    - `인포그래픽만들기.py`: CSV를 읽어 평균·비중·배수를 계산하고 → HTML 인포그래픽 → 크롬으로 PNG(2배 선명)·PDF(A4 1쪽) 저장. `결과/아이콘/`에 그림이 있으면 자동으로 넣음
    - `카드뉴스_원고.md`: 같은 숫자 3개로 쓴 카드뉴스 원고 6장 (08 `카드만들기.py`로 만듦)
  - `10_디자인_인포그래픽/인포그래픽결과/`: GitHub에 올리는 결과 사본
    - `1인가구_생활비_인포그래픽.jpg` / `.pdf`: 완성 인포그래픽 (아이콘 포함)
    - `아이콘_3장.jpg`: ChatGPT로 만든 아이콘 3장 (지갑·집·헤드폰+게임패드)
    - `비교_아이콘없음_있음.jpg`: 아이콘 없는 판과 있는 판을 나란히 놓은 것
    - `카드뉴스_한눈에보기.jpg`: 카드뉴스 6장을 한 장에 모아 본 것
  - (원본 PNG·HTML·아이콘 원본·카드별 PNG는 `10_디자인_인포그래픽/결과/`에 있고, GitHub에는 올리지 않음)
  - 새로 설치한 도구 없음 (파이썬 기본 기능 + 크롬 + ffmpeg)

## 💡 새 개념

- **인포그래픽 = 숫자 3개 + 그림**: 숫자를 다 보여 주지 않고 "가장 말하고 싶은 것"만 골라 크게 쓴다. 나머지는 차트와 작은 글씨로 받친다
- **숫자는 코드가 계산해 넣기**: 손으로 적으면 데이터가 바뀔 때 틀린다. 코드가 CSV에서 직접 계산하니 다시 실행만 하면 된다
- **결론은 데이터가 말하는 만큼만**: 처음 결론 "나이가 들수록 모은다"는 저축이 40대(69.9만)가 50대 이상(57.1만)보다 많아서 틀렸다 → "여가비는 줄어든다"로 고쳤다
- **사람 수가 다르면 조심**: 50대 이상은 41명뿐이라, 작은 차이는 크게 말하지 않는다. 막대 옆에 사람 수를 같이 적었다
- **A4 크기 = 794×1123px**: 화면 픽셀로 A4를 맞추고, 크롬의 `--print-to-pdf`로 PDF 1쪽, `--force-device-scale-factor=2`로 2배 선명한 PNG를 만든다
- **`mix-blend-mode: multiply` + 흰색 맞추기**: AI 그림 배경이 아주 옅은 회색이라 네모가 비쳤다. 거의 흰색을 순수한 흰색으로 바꿔서 지웠다
- **한글 경로와 터미널**: 한글 폴더 이름을 치거나 붙여 넣으면 입력기 때문에 글자가 달라질 수 있다 → `cd 10*`(10으로 시작하는 폴더), `glob('data/*.csv')`처럼 한글 없이 찾는 방법이 안전하다
- **셸 변수 이름은 영어로**: `공통="..."`은 명령으로 오해돼 실패했다 → `COMMON="..."`
- **도구 재사용**: 08의 `카드만들기.py`를 고치지 않고 원고만 새로 써서 카드뉴스를 만들었다

## 📝 포트폴리오 한 줄

- **문제:** 설문 데이터(300명 × 6개 항목)를 표로만 보여 주면 사람들이 읽지 않고, 숫자를 손으로 옮기면 틀리기 쉽다
- **해결:** 말하고 싶은 숫자 3개를 고르고, 파이썬이 CSV에서 직접 계산해 A4 세로 인포그래픽(도넛·아이콘·막대 차트)을 HTML로 만든 뒤 PNG·PDF로 저장했다. 같은 숫자로 카드뉴스 6장도 만들었다
- **효과:** 명령어 한 줄로 인포그래픽 PNG·PDF 완성. 직접 검산으로 숫자가 원본과 같은 것을 확인했고(57.7만 원), 데이터와 안 맞는 결론 한 문장을 찾아 고쳤다

## 💬 느낀 점 (Claude가 대신 작성, 내가 확인)

- 표로 보면 그냥 숫자였는데, 3개만 골라 크게 쓰니 "혼자 살면 10원 중 4원은 집값"이라는 이야기가 바로 보였다. 무엇을 뺄지 고르는 게 디자인의 절반이었다.
